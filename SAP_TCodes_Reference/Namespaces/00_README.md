## 💡 What are Namespace T-Codes?

```
Format: /NAMESPACE/TCODENAME
Example: /SCWM/MON
         │
         SCWM = Extended Warehouse Management
         MON  = Monitor T-code

These are SAP-delivered T-codes for:
→ Industry solutions (EWM, TM, APO etc.)
→ Add-on components (Fiori, Gateway etc.)
→ Localization solutions (GTS, SLL etc.)
→ Specialized modules (EHS, DSD etc.)
```
